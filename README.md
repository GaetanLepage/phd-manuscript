# PhD Manuscript

This repository hosts the source code for my PhD manuscript.
The thesis is titled _From Sound to Action: Deep Learning for Audio-Based Localization and Navigation in Robotics_ and was supervised by the great [Dr. Xavier Alameda](https://xavirema.eu), [Pr. Laurent Girin](https://www.gipsa-lab.grenoble-inp.fr/user/laurent.girin) and [Dr. Chris Reinke](https://www.chris-reinke.com/).

- The slides for the defense can be found [here](https://github.com/GaetanLepage/phd_defense_slides).
- You can find the PDF document on [theses.fr](https://theses.fr/2025GRALM028).
- The project can also be viewed [on the Typst web app](https://typst.app/project/rsAAFv6wYyjDI8QG1Hyly5)

This document is written in [Typst](https://typst.app), a modern typesetting tool.
I had a very pleasant time working with Typst as it allowed me to work flawlessly on a large document.
I am very thankful to the team behind this great tool. The community is also very helpful!

To compile the document, simply do:
```bash
typst compile main.typ
```
